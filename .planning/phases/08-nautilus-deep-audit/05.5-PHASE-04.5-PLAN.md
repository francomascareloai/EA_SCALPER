## CRITIC Focus Areas

### 1. Feature Engineering (HIGHEST RISK)

**Questions to Answer:**
1. Are features computed using only past data?
2. Is there any rolling calculation that peeks ahead?
3. Are target labels properly aligned (no off-by-one)?
4. Is there leakage from test set to training set?

**Red Flags:**
- `df.shift(-1)` or negative shift values
- `.rolling().apply()` with center=True
- Target calculated from future returns without shift
- MinMax/StandardScaler fit on entire dataset
- **LabelEncoder/OneHotEncoder fit on full dataset** (leaks future category knowledge)
- **Discretization bins computed on full dataset**

**Pandas-Specific Traps (MANDATORY CHECK):**
- `.ffill()` - can propagate future values if index is inverted or misused
- `.bfill()` - ALWAYS suspect: fills from future by definition
- `.interpolate()` - can use future points depending on method
- Datetime index `.loc` slicing confusion (inclusive vs exclusive bounds)
- `DataFrame.reindex()` with fill_method - can introduce leakage

### 2. Ensemble Predictor

**Questions to Answer:**
1. Does inference use only available data?
2. Is feature pipeline identical to training?
3. Is model loaded correctly (no training during inference)?
4. Are predictions properly aligned with bars?
5. Are ensemble voting weights determined on training/validation only (not test)?

**Red Flags:**
- Different feature calculation in training vs inference
- Using future bars in feature window
- Model re-training during backtest
- Ensemble weights tuned on test performance (look-ahead)

### 3. Model Trainer

**Questions to Answer:**
1. Is train/test split temporal (not random)?
2. Is there proper embargo between train and test?
3. Are hyperparameters tuned on validation, not test?
4. Is cross-validation temporal (TimeSeriesSplit)?
5. Is walk-forward validation used? If so, document the schedule.

**Red Flags:**
- `train_test_split(shuffle=True)` on time series
- No purging/embargo between folds
- Feature selection using full dataset
- Hyperparameter tuning on test data
- Online learning updates using future data

### Data Dependencies

### Temporal Integrity Check
- Feature at time T uses only data from times <= T: YES/NO
- If rolling/expanding window: is center=False confirmed? YES/NO

### Temporal Trace

### Three Types of ML Data Leakage (NIH/PMC Academic Paper)

#### Type 1: Overlap Leakage
Same samples in train and test sets. Common cause: SMOTE/resampling BEFORE split.

```python
# WRONG (Line 6-7 pattern from research)
X_resampled, y_resampled = smote.fit_resample(X, y)
X_train, X_test = train_test_split(X_resampled, y_resampled)  # LEAK!

# RIGHT
X_train, X_test, y_train, y_test = train_test_split(X, y)
X_train_res, y_train_res = smote.fit_resample(X_train, y_train)  # After split
```

#### Type 2: Multi-Test Leakage
Shared test set across experiments leads to implicit overfitting.

#### Type 3: Pre-Processing Leakage
Preprocessing uses test set information.

```python
# WRONG
scaler = MinMaxScaler()
X_scaled = scaler.fit_transform(X)  # Uses full dataset statistics
X_train, X_test = train_test_split(X_scaled)  # LEAK!

# RIGHT
X_train, X_test = train_test_split(X)
scaler = MinMaxScaler()
X_train_scaled = scaler.fit_transform(X_train)  # Fit on train only
X_test_scaled = scaler.transform(X_test)  # Transform only
```

### Statistical Validation Additions (PBO/DSR)

The ARGUS research identifies two critical statistical measures to validate strategy results are not overfit:

| Metric | Threshold | Purpose | Status |
|--------|-----------|---------|--------|
| PBO (Probability of Backtest Overfitting) | < 20% | Probability that in-sample performance is due to overfitting | [ ] |
| DSR (Deflated Sharpe Ratio) | > 0 | Sharpe ratio corrected for selection bias and non-normality | [ ] |
| WFE (Walk-Forward Efficiency) | >= 0.6 | Out-of-sample vs in-sample performance ratio | [ ] |

**Implementation Note:** PBO can be calculated using CPCV (Combinatorial Purged Cross-Validation) from Bailey & Lopez de Prado.
