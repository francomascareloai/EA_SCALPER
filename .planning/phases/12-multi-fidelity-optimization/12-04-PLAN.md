  <action>
    Create spread buffer gate that rejects trades with SL too close to entry:

    ```python
    class SpreadBufferGate:
        """Reject trades where SL is too tight relative to spread."""

        def __init__(self, min_sl_spread_ratio: float = 3.0):
            self.min_sl_spread_ratio = min_sl_spread_ratio

        def check(self, sl_distance: float, current_spread: float) -> GateResult:
            """Check if trade passes spread buffer requirement."""
            required_distance = current_spread * self.min_sl_spread_ratio
            if sl_distance < required_distance:
                return GateResult(
                    passed=False,
                    reason=f"SL too tight: {sl_distance:.1f} < {required_distance:.1f} (3x spread)"
                )
            return GateResult(passed=True)
    ```

    WHY 3x spread: Standard industry practice. SL closer than 3x spread has:
    - High probability of slippage loss
    - Poor risk/reward after costs
    - High sensitivity to spread widening

    Integration with VirtualGate: Add spread check to pre-flight validation.
