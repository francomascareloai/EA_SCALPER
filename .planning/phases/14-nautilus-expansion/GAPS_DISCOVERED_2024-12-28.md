## Gap R1: TradingState Risk Control (REDUCING/HALTED) - CRITICAL
- **What it does**: RiskEngine supports three TradingState modes that control order flow at the engine level:

- **Source**: `/external/nautilus_trader/crates/risk/src/engine/mod.rs:508-527`, `/external/nautilus_trader/docs/concepts/execution.md:135-140`
- **Why we should use it**: Perfect for Apex DD compliance. When trailing DD hits 4.0%, set state to `REDUCING` to prevent new positions while allowing emergency closes. At 4.5% set to `HALTED`. Currently we have manual `_set_trading_state()` in base_strategy but not using RiskEngine's built-in enforcement.
- **Integration effort**: LOW
- **Priority**: CRITICAL (Apex safety)

# AREA 2: EXECUTION/ORDER MANAGEMENT

## Gap E1: Bracket Orders (OTO + OCO) - CRITICAL
- **What it does**: Atomic entry + SL + TP in a single order list. Entry triggers both SL and TP as child orders (OTO = One-Triggers-Other). SL and TP are linked as OCO (One-Cancels-Other).
- **Source**:
  - `external/nautilus_trader/nautilus_trader/common/factories.pyx:1193` (bracket method)
  - `external/nautilus_trader/docs/concepts/orders.md:575-643`
  - `external/nautilus_trader/examples/live/interactive_brokers/notebooks/test_bracket_order.py:98`
- **Why we should use it**:
  - **CRITICAL for Apex compliance**: Currently we submit entry MARKET, then SL in separate steps. There is a DANGEROUS window between entry fill and SL acceptance where position has NO protection.
  - **Atomic safety**: Bracket ensures SL is GUARANTEED to be active once entry fills.
  - **Reduce latency**: One network round-trip instead of two sequential submits.
- **Example**:
  ```python
  order_list = self.order_factory.bracket(
      instrument_id=instrument_id,
      order_side=OrderSide.BUY,
      quantity=qty,
      entry_order_type=OrderType.MARKET,
      sl_trigger_price=sl_price,
      sl_order_type=OrderType.STOP_MARKET,
      tp_price=tp_price,
      tp_order_type=OrderType.LIMIT,
      contingency_type=ContingencyType.OCO,
  )
  self.submit_order_list(order_list)
  ```
- **Integration effort**: MEDIUM
- **Priority**: CRITICAL (eliminates SL protection gap)
