### 3. Error Recovery (Seção 8) ✅
**FORGE: 3-Strike Compilation Protocol**
1. Attempt 1 (Auto): Verify includes → Recompile → Read log
2. Attempt 2 (RAG): Query mql5-docs → Apply fix → Recompile
3. Attempt 3 (Human): Report + Ask → NEVER 4+ attempts

**ORACLE: Backtest Non-Convergence**
- Data sufficient? (min 500 trades)
- WFE calculation correct?
- If both OK → Report "insufficient edge" → BLOCK

**SENTINEL: Circuit Breaker Scenarios**
- ALL setups blocked 3 days → Report tight parameters
- DD >9% → EMERGENCY MODE
- Time >4:55 PM → FORCE CLOSE

**Benefício**: Sistema nunca trava, sempre tem protocolo de recovery
